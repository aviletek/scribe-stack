📖 How to Use This App

🚀 Getting Started

  • Notebook Name: Click on the notebook name at the top to rename your notebook.
  • Add Notes: Click the + icon button to create a new note.
  • Quick Entry: Only Title and Content are required - other fields have smart defaults.
  • New Stack: Click "New Stack" to clear all notes and start fresh.

📝 Note Categories

  • Default Categories: Personal, Work, Ideas, Learning, Action, Archive, and Private.
  • Action Category: Special category with status tracking (Not Started, In Progress, Completed, Deferred, Cancelled), progress bar, and due dates.
  • Archive Category: Hidden from main view - use to store completed or inactive notes. Select "Archive" filter to view.
  • Private Category: Only available for encrypted files. Requires password each time you access. Hidden from main view.
  • Custom Categories: Click "Manage Categories" in the sidebar to add your own with status tracking.
  • Filter Counts: Category and status filters show note counts in parentheses.

⭐ Rating System

  • Rate your notes from 1 to 5 stars based on importance or priority.
  • Click on the stars when creating or editing a note to set the rating.
  • Use the rating filter to find your most important notes quickly.

✍️ Rich Text Editor

  • Formatting: Use bold, italic, underline, and strikethrough.
  • Headers: Create headings (H1, H2, H3) for organization.
  • Lists: Add ordered (numbered) or unordered (bullet) lists.
  • Colors: Change text color and background highlight.
  • Code: Add inline code or code blocks for technical notes.
  • Links: Insert clickable hyperlinks within your content.
  • Images: Click the image icon or paste from clipboard to embed images (auto-compressed).
  • Tables: Tables from external sources display correctly when pasted.

🔗 Linking Notes

  • Link Related Notes: Select other notes to link when creating or editing.
  • Click to Navigate: Click on linked note IDs to view connected notes.
  • URL Links: Type https://example.com or use markdown: [Link Text](url)

📎 File Attachments

  • Add Files: Click "Add Files" in the note form to attach documents, images, etc.
  • File Limits: Maximum 25MB per file, 100MB total per note.
  • Any File Type: Images, PDFs, Word docs, spreadsheets, and more.
  • Download: Click on attachment names to download files.
  • Portable: Attachments are embedded and travel with your notebook file.

💾 Save & Open

  • Save (disk icon): Save your notes to a JSON file. First save prompts for encryption choice.
  • Autosave: After first save or open, changes auto-save to your file.
  • Open (folder icon): Load notes from a previously saved file (enables autosave).
  • Print (printer icon): Generate a printable PDF report of all notes.
  • Print Note: Click "Print" in the View modal to print a single note.

🔐 Password Protection (Encryption)

  • Encrypted Export: When saving, choose to password-protect your backup.
  • AES-256 Encryption: Uses military-grade AES-GCM encryption for security.
  • Import Encrypted: Automatically detects encrypted files and prompts for password.
  • File Extension: Encrypted files are saved as .encrypted.json
  • Private Category: Only available when file is encrypted - stores sensitive notes that require password to view.
  • Encryption Settings: Click "Encryption Settings" in the sidebar to enable/change encryption.
  • ⚠️ Important: Remember your password - there's no recovery if forgotten!

🔒 Privacy Mode

  • Activate: Click the eye icon (with strike-through) to instantly blur the screen.
  • Deactivate (Desktop): Press Shift + Enter to reveal content.
  • Deactivate (Mobile): Double-tap anywhere on the blurred overlay.
  • Persists: Privacy mode stays active even after page refresh.

📊 Statistics & Filters

  • Overview Panel: See total notes, action items, and average rating.
  • Status Panel: Track action notes by status (Not Started, In Progress, etc.).
  • Rating Panel: View distribution of notes by star rating.
  • Category Panel: See breakdown by category.
  • Filters: Filter notes by category, rating, or status from the sidebar.

🔍 Search & Sort

  • Search: Find notes by title, content, or note ID.
  • Sort Options: Sort by ID, Rating, Category, Date, Status, or Due Date.
  • Due Soon: Shows notes due within 48 hours (excludes completed/cancelled).
  • Overdue: Shows only notes past their due date (excludes completed/cancelled).
  • Due Soon Banner: A notification banner appears when items are due soon.

🌙 Other Features

  • Dark/Light Mode: Toggle between themes using the moon/sun icon.
  • Auto-Save: After first save or open, changes auto-save to your file automatically.
  • Session Storage: Notes persist in browser storage per tab until you save to file.
  • Mobile Friendly: Use the hamburger menu to access sidebar on mobile devices.
  • Inline Editing: Click "Edit" on any note card to edit directly without a modal.
  • Expand Notes: Click on any note card to expand and see full details.
  • View Modal: Click "View" for a detailed read-only view with print option.
  • File Info Bar: Shows current file name, path, last modified time, and encryption status.
